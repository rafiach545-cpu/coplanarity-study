# References used in 07_atlas_real_geometry

Each PDF is in `pdf/` (checksums in `MD5SUMS_pdf.txt`). Its text, extracted with `pdftotext -layout`, is in `text/`. All files were downloaded on 2026-11-15.

Every number used in `geometry/` and `backgrounds/` names its reference ID (R1, R2, ...) and the table, section or equation it comes from. Each value has one of these statuses:

- **VERIFIED:** the value was read in the reference text.
- **DERIVED:** the value was computed from verified values. The computation is written next to it.
- **CONFLICT:** two references disagree. Both values are kept, and the reason for the choice is written next to them.

## Conflicts and open points

1. **IBL radius:** 33.25 mm (R1) or 33.5 mm "centre of the sensor radius" (R2 Table 1). We keep 33.25 mm, the same value as Stages 1–2.
2. **IBL material:** 1.88% X0 (R2) or ≈ 1.5% X0 (R6). The choice must be stated in the report. A ±20% variation can serve as a systematic.
3. **Run 2 beam pipe material:** R6 gives the composition (0.8 mm Be plus tapes) but no single X/X0 number. Our 0.227% X0 is the Be wall only (DERIVED). The Run 1 value of 0.45% integrated to r = 36 mm (R3 Table 4.15) is for a different, thicker pipe.
4. **IBL resolution:** a value of 8 × 40 µm was quoted in an earlier note. It was not found in any reference, so 10 × 60 µm (R1) is used.
5. **Module gaps and tilts:** not public as positions. The ATLAS GeoModel database is not public. Gaps would have to be built from stave counts, tilts and overlaps (R2 Table 1 gives the IBL φ overlap of 1.82°).
